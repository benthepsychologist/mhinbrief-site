GST/HST exemption for behavioural-health services doesn't run through a
single blanket rule — it runs through several separate provisions, each
keyed to a different profession, each carrying its own conditions. The
matrix below is every route this registry has traced and verified so far,
one row per profession, each with its citation, its verbatim statutory
text, and the date we last checked it against the primary source.

This page is built to hold more than the federal government. As
provincial sales-tax wrinkles or new professions clear verification, they
land here as new rows — the table grows; the page doesn't get redesigned.
